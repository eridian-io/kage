# Kage docs

| Folder or file | What's in it |
|---|---|
| [`design/`](design/) | The UI design target. [`kage-board.html`](design/kage-board.html) is the approved desktop design: open it in a browser and click through the states. [`reference/`](design/reference/) holds screenshots of each state, which the visual tests compare against. [`explorations/`](design/explorations/) keeps the earlier options for history. |
| [`specs/`](specs/) | Design documents: what Kage does, how it works, and why. |
| [`plans/`](plans/) | Implementation plans, broken into small steps with tests. |
| [`backlog.md`](backlog.md) | Work deliberately left for a later phase, each item with its reason. |

When the design changes, update `design/kage-board.html` and the screenshots in `design/reference/` in the same pull request as the code.
