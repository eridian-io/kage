Kage board

This is the approved desktop design (Variant 1, "Quiet", 2026-11-21). The real app must match it: the layout, the colours, the type and the behaviour shown here. Click the sessions to see each state. Open a finished session and try Delete. All data is sample data.

States to check

  • web / dark mode: needs you, with a question and answer buttons
  • shop-api / fix login bug: running, with a live cursor and a thinking line
  • docs / update README: done, with a follow-up field and an unpushed commit; try Delete…
  • shop-api / rate limit v1: done and pinned

Colour rules

  • Lime only for what's alive or actionable: New task, the selected row's edge, the live cursor, the thinking line, preview links, the running chip
  • Amber only for "needs you"
  • Muted red only for Stop and Delete
  • The "kage" wordmark stays off-white

Layout rules

  • Three columns: session list 250 px, session, preview pane 250 px
  • Thin lines, no boxes, no glows or pulses
  • Every action sits in the footer under the output: Terminal on the left, Stop / Archive / Delete on the right
